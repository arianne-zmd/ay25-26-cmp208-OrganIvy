Privacy Policy

Privacy Policy

Introduction

OrganIvy is an Android application designed to help users manage digital photo clutter through cleanup and gamified features. This Privacy Policy explains how information is collected, used, and protected when using the application.

By using OrganIvy, users agree to the collection and use of information in accordance with this policy.

Information Collected

Account Information

OrganIvy uses Firebase Authentication to provide secure login and account management features. When creating an account, the application may collect:

  • Email address
  • User authentication information

This information is securely managed through Firebase services.

Device Storage Access

OrganIvy requires storage permissions to access photos stored on the user’s device. These permissions are used only to:

  • Scan and categorize images
  • Detect duplicate, blurry, large, or old photos
  • Allow users to manage and delete unwanted images
  • Display photo galleries within the application

The application only accesses images after permission has been granted by the user.

Secure Folder Storage

Images added to the Secure Folder feature may be stored using Firebase services to allow protected access and backup functionality.

Users are responsible for maintaining the confidentiality of their Secure Folder password.

App Progress Data

OrganIvy stores user progress data, including:

  • Cleanup statistics
  • Coins and rewards
  • Badges and achievements
  • Virtual plant progress
  • Streak information
  • Environmental impact estimates

This information is used to improve user experience and maintain gamification features within the application.

How Information Is Used

Collected information is used to:

  • Provide and maintain application functionality
  • Authenticate users securely
  • Categorize and organize device images
  • Track cleanup progress and achievements
  • Improve application performance and user experience
  • Support environmental impact calculations

Photo Deletion

OrganIvy allows users to permanently delete photos from their devices. A two-step confirmation process is implemented to reduce accidental deletions.

Users are responsible for reviewing selected images before confirming deletion.

Data Security

OrganIvy takes reasonable measures to protect user information and stored data. Authentication and secure cloud services provided by Firebase are used to improve account and data security.

However, no method of electronic storage or transmission over the internet is completely secure.

Third-Party Services

OrganIvy uses Firebase services provided by Google for:

  • User authentication
  • Secure data storage

These services may collect information in accordance with their own privacy policies.

User Rights

Users may:

  • Revoke storage permissions through device settings
  • Delete their account information
  • Remove stored images from the Secure Folder
  • Stop using the application at any time

Changes to This Privacy Policy

This Privacy Policy may be updated periodically. Changes will be reflected within the application.

External Links

OrganIvy will display environmental facts that include links to external websites and sources for educational purposes. When users open these links, they are redirected to third-party websites that are not controlled or operated by OrganIvy.

OrganIvy is not responsible for the privacy practices, content, or policies of external websites. Users are encouraged to review the privacy policies of any third-party sites they visit.

Contact

If users have questions regarding this Privacy Policy, they may contact the application developers for further information.
